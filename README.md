# Практическая работа №4: Паттерн «Шаблонный метод» (Template Method)

## Информация о работе
- **Тема:** Реализация поведенческого паттерна «Шаблонный метод» на C#
- **Платформа:** Консольное приложение (.NET)

## Цель работы
Закрепить теоретические знания по теме «Поведенческие паттерны проектирования» и получить практические навыки реализации паттерна **«Шаблонный метод» (Template Method)** в консольном приложении на языке C#.

## Описание проекта
Консольное приложение **«Система обработки заказов»**, демонстрирующее работу паттерна «Шаблонный метод». Система позволяет обрабатывать два типа заказов — **обычный** и **премиум** — через единый алгоритм, при этом отдельные шаги алгоритма переопределяются в подклассах.

## Структура проекта

### 1. `OrderProcessor` (абстрактный класс — шаблонный класс)
Содержит **шаблонный метод** `ProcessOrder(decimal amount)`, который определяет скелет алгоритма:

1. `ValidateOrder(amount)` — проверка заказа
2. `CalculateDiscount(amount)` — расчёт скидки
3. `ProcessPayment(amount - discount)` — обработка платежа
4. `SendNotification()` — отправка уведомления
5. `LogOrder()` — логирование заказа (общий метод)

**Абстрактные методы** (реализуются в подклассах):
- `ValidateOrder(decimal amount)`
- `CalculateDiscount(decimal amount)`
- `ProcessPayment(decimal amount)`
- `SendNotification()`
- `DisplayName` (свойство)

**Конкретный метод** (общий для всех):
- `LogOrder()` — выводит сообщение о завершении обработки.

### 2. Классы-наследники

| Класс | Особенности |
|-------|-------------|
| `RegularOrderProcessor` | Обычный заказ. Скидка — 0%. Стандартная проверка и оплата. |
| `PremiumOrderProcessor` | Премиум-заказ. Скидка — 15%. Расширенная проверка, приоритетная оплата. |

### 3. `OrderManager` (менеджер заказов)
- Хранит список выполненных заказов (`List<string>`).
- `ProcessOrder(OrderProcessor processor, decimal amount)` — обрабатывает заказ через переданный процессор и сохраняет информацию.
- `ShowAllOrders()` — выводит все выполненные заказы.
- `ClearAllOrders()` — очищает список.
- `Count` — текущее количество заказов.

### 4. `Program` (точка входа)
- Выводит информацию об авторах и работе.
- Запускает **демонстрацию паттерна** (`DemonstrateTemplateMethod`).
- Реализует **интерактивное меню** из 5 пунктов.

## Функциональные возможности

### Главный экран
При запуске выводится:
- Фамилия и имя студентов.
- Название группы.
- Название практической работы.
- Краткое описание.

### Интерактивное меню

| № | Пункт | Действие |
|---|-------|----------|
| 1 | Оформить обычный заказ | Создаёт `RegularOrderProcessor`, запрашивает сумму, обрабатывает заказ |
| 2 | Оформить премиум-заказ | Создаёт `PremiumOrderProcessor`, запрашивает сумму, обрабатывает заказ |
| 3 | Показать все заказы | Вызывает `ShowAllOrders()` |
| 4 | Очистить список заказов | Вызывает `ClearAllOrders()` и выводит текущее количество |
| 5 | Выход | Завершает работу приложения |

### Подтверждение действий
После каждой операции выводится сообщение с актуальным количеством заказов, например:
```
Заказ на сумму 1500 руб. обработан как ОБЫЧНЫЙ. Всего заказов: 3
```

### Демонстрация паттерна
В методе `Main` отдельный блок `DemonstrateTemplateMethod()`:
- Создаёт экземпляры `RegularOrderProcessor` и `PremiumOrderProcessor`.
- Через базовый класс `OrderProcessor` выполняет по одному заказу каждым обработчиком.
- Показывает, что клиентский код работает одинаково с разными типами заказов благодаря шаблонному методу.
